# CSV Visualizer App

Simple browser-based app to upload a CSV, preview rows, and visualize numeric columns.

## Run

1. Open `csv-visualizer-app/index.html` in a browser.
2. Upload a `.csv` file.
3. Pick X-axis, Y-axis, and chart type.
4. Click **Render Chart**.

## Notes

- Supports comma-separated CSV files with a header row.
- Data preview shows up to 100 rows.
- Charting uses Chart.js via CDN.
